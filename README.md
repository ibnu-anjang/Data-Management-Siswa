# Student Management App (Data Management Siswa)

Aplikasi manajemen data siswa berbasis **Flutter** dan **Firebase** dengan pembagian peran Client & Admin.

## 📁 Struktur Direktori

```text
data_management_siswa/
├── docs/                           # Dokumentasi teknis & alur proyek
├── design/                         # Asset UI/UX design & visual tokens
├── firebase/                       # Konfigurasi Firestore rules & indexes
│   ├── firestore.rules
│   └── firestore.indexes.json
├── frontend/                       # Source code aplikasi Flutter
│   ├── android/
│   ├── ios/
│   ├── web/
│   ├── assets/
│   ├── lib/
│   └── pubspec.yaml
├── .gitignore
├── firebase.json
└── README.md
```

## 🚀 Memulai (Quick Start)

### Run Aplikasi Flutter
```bash
cd frontend
flutter pub get
flutter run
```

## 📚 Dokumentasi
Silakan me-refer dokumen di folder [`docs/`](docs/00_README.md) untuk detail alur pengguna, UI design system, dan arsitektur aplikasi.
