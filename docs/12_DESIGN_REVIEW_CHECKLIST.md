# Design Review Checklist

## Hierarchy
- [ ] Primary purpose is obvious
- [ ] Main action is clear
- [ ] Secondary actions are subordinate
- [ ] No unnecessary visual competition

## Layout
- [ ] Consistent 4-point spacing
- [ ] Alignment is consistent
- [ ] No overflow
- [ ] Safe areas respected
- [ ] Works on small phone widths

## Typography
- [ ] One font family
- [ ] Heading levels consistent
- [ ] Body readable
- [ ] No oversized text without purpose

## Components
- [ ] Same action uses same component
- [ ] Inputs consistent
- [ ] Buttons consistent
- [ ] Dialogs consistent
- [ ] Icons have clear meaning

## Visual quality
- [ ] No unnecessary gradients
- [ ] No excessive rounded containers
- [ ] No excessive shadows
- [ ] No fake decorative statistics
- [ ] No random icons
- [ ] No generic AI dashboard patterns

## UX
- [ ] Loading state
- [ ] Empty state
- [ ] Error state
- [ ] Success feedback
- [ ] Delete confirmation
- [ ] Predictable back behavior

## Accessibility
- [ ] Contrast readable
- [ ] Touch targets adequate
- [ ] Meaning not color-only
- [ ] Actions understandable without icons alone

## Approval
- [ ] APPROVED
- [ ] REVISE
