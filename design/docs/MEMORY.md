## 🎯 Directives & User Preferences
- **Design Philosophy:** Prototype must feel like a real 1:1 working app that a frontend engineer can execute 1-to-1 into Flutter & Firebase.
- **Zero Browser Popups:** No browser `alert()` or `prompt()`. All interactions are native HTML Card Modals inside the simulator frame.
- **Natural Indonesian Copy:** Copy must be warm, friendly, modern (Tokopedia/Gojek/Notion style)—no stiff bureaucratic Bahasa Baku.
- **Priorities:**
  - Admin (`★★★★★`): Login, Dashboard, Student CRUD, Rombel CRUD, Delete Confirmation, Search, Filter.
  - Client (`★★☆☆☆`): Login, Home Recap, Read-Only Student List, Search, Filter, Profile.
